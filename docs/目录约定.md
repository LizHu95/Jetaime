# 本地数据、生成产物与部署定义

| 目录 | 职责 | Git 管理 |
| --- | --- | --- |
| `deploy/` | 部署脚本、systemd 配置和无密钥模板 | 提交 |
| `local/` | 实际配置、凭据、私有输入和持续保存的状态 | 整体忽略 |
| `outputs/` | 构建、部署打包、评测与检查生成的产物 | 整体忽略 |

```text
deploy/
  api/                     统一 HTTP API 构建脚本与说明
  feishu/                  构建、安装、更新脚本及服务模板
  phoenix/                 Phoenix 启动脚本
local/
  .env                     本地开发凭据，启动入口自动加载
  models.json              实际模型配置
  feishu/.env              飞书独立部署凭据
  notes/                   私人文档
  data/
    chat-history/          原始聊天与输入 fixture
    assistant/             消息、待办状态及持续运行日志
    evals/                 案例工作稿、审核材料与私有准备脚本
      versions/            冻结案例、manifest 与运行登记
    phoenix-v2/            当前 Phoenix 数据库
    archive/phoenix-legacy/ 原 deploy/data/phoenix 数据库
    migrations/            目录迁移记录与文件哈希
outputs/
  api/                     Linux 二进制、配置示例、校验清单与部署压缩包
  feishu/
    deploy/                Linux 二进制、配置副本和安装文件
    feishu-deploy.tar.gz    部署压缩包
  evals/                   实验结果、汇总与源码快照
    reports/               生成的评测分析报告
  agent-check/             本地链路验证结果
```

模型和凭据配置是输入，放 `local/`；由构建脚本复制到部署目录的配置副本属于产物，放 `outputs/`。持续运行的数据库和业务状态放 `local/data/`，一次检查或评测产生的记录放 `outputs/`。

生成产物也可能含有密钥或聊天片段。`outputs/` 不能公开提交。部署包可重新生成；实验快照、结果和汇总可能是唯一的历史证据，删除前应成套归档。冻结案例与历史快照不因目录整理而改写。

完整迁移清单位于本地 `local/data/migrations/20261014-boundaries.json`。历史 metadata、源码快照及运行登记中的旧路径保持不变；报告工具通过 `scripts/artifact_paths.py` 解析旧路径。

`.gitignore` 对 `local/` 和 `outputs/` 使用仓库根目录规则；旧 `deploy/data/`、`evals/output/` 等路径继续忽略，以防旧命令重新生成私有文件。`deploy/` 中的无密钥模板正常提交。

统一 HTTP API 的构建产物放在 `outputs/api/`；`deploy/api/` 仅保留构建脚本和说明。其他服务与评测产物继续使用现有 `outputs/` 目录。
