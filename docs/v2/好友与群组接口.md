# 好友与群组接口

更新：2026-10-14。固定双人群；活跃群就是联系关系，没有独立好友表。发送添加申请后，由接收方接受，原子创建一个群、两位真人成员和一个共享 AI 助手。拒绝、取消或仅发送申请都不会创建群。群列表已关联文字聊天、实时同步及共享 AI，见 [双人群聊接口](双人群聊接口.md)。

正式服务固定装配好友群组模块，`make dev` 直接启动。沿用已有数据库结构，无需新增迁移。所有接口使用 `Authorization: Bearer TOKEN`，逐次查询数据库验证会话有效期及撤销状态；调用人由 Token 确定，不接受客户端指定操作人。返回 `Cache-Control: no-store`。

| 方法与路径 | 输入 | 成功响应 |
| --- | --- | --- |
| GET /api/contacts/users?username=Bob | 完整账号，区分大小写 | 200，`{id,username,nickname}` |
| POST /api/contacts/requests | JSON `{"username":"Bob"}` | 200，添加申请；重复或反向申请返回同一条 pending 申请 |
| GET /api/contacts/requests | 无 | 200，本人的最近 100 条收发申请数组 |
| POST /api/contacts/requests/{id}/accept | 无需请求体，仅接收方 | 200，accepted 申请，含 groupId |
| POST /api/contacts/requests/{id}/reject | 无需请求体，仅接收方 | 200，rejected 申请 |
| POST /api/contacts/requests/{id}/cancel | 无需请求体，仅发送方 | 200，cancelled 申请 |
| GET /api/groups | 无 | 200，本人所属 active 群数组 |

申请结构：`{id,from,to,status,groupId,createdAt}`；from/to 是上述用户结构，未接受时 groupId 为 null。群结构：`{id,peer,status,assistantId,assistantName,createdAt}`。用户查找仅支持精确账号，不支持枚举或模糊搜索。

申请 JSON 最多 8 KiB，不接受额外字段。不能添加自己；已有活跃群时返回 409。不会自动接受反向申请。相同用户对的发送和处理在 PostgreSQL 事务中通过同一 advisory lock 串行化，再锁定申请行；群、成员、助手和申请状态一次提交。数据库唯一索引与延迟完整性触发器提供最后一道约束。

同一操作可重复执行，返回原状态；已处理申请不能切换为另一终态。重复接受返回原 groupId，即使群后续关闭，也不会创建新群。第三方访问申请返回 404；参与人使用不符合角色的动作返回 403。

| 状态码 | error.code | 含义 |
| --- | --- | --- |
| 400 | invalid_input | 账号、申请 ID、动作不合法或添加自己 |
| 400 | invalid_json | JSON 错误或包含未知字段 |
| 401 | unauthorized | 登录无效、过期或撤销 |
| 403 | forbidden | 发送人不能接受/拒绝，接收人不能取消 |
| 404 | not_found | 账号或本人可见申请不存在 |
| 409 | already_connected | 已有活跃群 |
| 409 | request_conflict | 申请已进入其他终态 |
| 413 | request_too_large | 请求体超过 8 KiB |
| 415 | unsupported_media_type | 发送申请需 application/json |
| 500 | internal_error | 服务内部失败，不暴露数据库详情 |

Web 入口为 `/page/contacts/`；登录成功页提供“加好友 / 创建群”入口。页面可查找用户、发送申请、接受/拒绝/取消申请、查看双方群与共享助手，每 10 秒刷新收发申请及群列表，重新聚焦也会刷新；收到 unauthorized 后清除本地登录并跳转登录页。

验证：Go PostgreSQL 集成测试覆盖双向并发发送、重复并发接受、成员/助手数量、越权和群隔离、取消/拒绝幂等、旧 Token 拒绝。运行 `python3 scripts/check-account-flow.py` 可在临时 schema 上启动真实 API 和 Web，完成桌面及手机浏览器联调；脚本结束后停止自身启动的服务并删除测试 schema，不改动本地业务数据。需要 psql、本地 Go/Node、Chrome 和可创建 schema 的数据库连接。
