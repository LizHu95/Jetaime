# AI 情侣决策助手 V1 开发任务清单

依据：[产品方案](产品方案-V1.0.md)、[技术方案](技术方案-V1.0.md)、[领域模型与决策契约](领域模型与决策契约.md)。本文件只维护任务、依赖、验收和进展。

顺序：CLI 决策 → 数据与 HTTP → 小程序 → 集成发布。V1-01、V1-02 已完成首轮规则和默认虚构资料；V1-03、V1-05 已有可运行的 Mock CLI/Workflow 和 Ollama Provider 接入代码，V1-06 已有固定场景及模型 HTTP 适配测试。Embedding、真实模型效果评测、检索对照和生产接口尚未完成，不将模拟验证记作这些任务全部完成。

## 5 完成规则与下一步

任务需有交付文件、验证证据和状态更新才算完成；权限与异常随功能交付，不推迟到发布阶段补做。已有首轮结构规则行为测试，不代表真实模型或生产权限通过。

首轮实体、默认数据与内存 Mock CLI 闭环已运行；此前 make check 和完整 race 检查通过。Ollama 与可选 Phoenix 追踪已接入 CLI，测试服务验证了异常输出、取消、OTLP 协议、失败追踪及观测服务离线不影响业务；相关包的编译、vet、测试、race 和 lint 通过。一次真实 qwen3.5:9b 调用已保存到本地 Phoenix 并验证步骤树、Prompt/响应、Token 和耗时，尚不等同于推荐质量验收。已验证的事实仅是人工定义虚构资料；通用事实提取、解释披露校验、可变授权下 Session 失效、数据库事务及保留删除策略在后续任务落实。下一步利用 Trace 补齐模型输入的约束依据、验证解释一致性，再推进 V1-04 检索；规划、图片、分享和市场范围集中在产品方案及领域契约维护。
