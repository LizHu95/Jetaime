# AI 情侣决策助手 产品方案 V1.0

面向个人和情侣，将收藏的餐厅、菜谱、活动、电影等内容与长期偏好结合，帮助用户做决定。正式入口为微信小程序，核心闭环为收藏 → 空间共享 → 偏好匹配 → 决策 → 反馈。

本文集中定义产品范围与页面行为；领域关系和扩展契约见[领域模型与决策契约](领域模型与决策契约.md)，技术选择见[技术方案](技术方案-V1.0.md)，实施安排见[任务清单](开发任务清单-V1.0.md)。

## 1 本期范围

| 模块 | P0 交付 |
| --- | --- |
| 用户与空间 | 微信登录、资料、自动个人空间、情侣创建邀请、空间切换 |
| 笔记与收藏 | 文本和链接录入、标题类型标签、详情编辑删除、空间收藏与移除 |
| 长期记忆 | 分别维护喜好、排斥和硬约束；推断可确认、纠正和删除 |
| 决策 | select 任务：从当前空间合法候选中给最多 Top 3，并解释参与人匹配 |
| 反馈与历史 | 对方案采纳、拒绝、换一批，保存可追溯的决策记录 |

图片上传和多模态理解为 P1，可延期。一天安排、多日旅行、多空间扩展与分享市场在本期考虑结构边界，但不因此新增所有功能验收。定位、距离排序、地图、自动同步外部收藏、公开社区、关注评论、复杂 Feed、多 Agent 和微服务不进入当前 P0。

## 2 页面与主流程

主导航为收藏、AI 决策、我的；空间切换放在收藏页，决策页始终展示当前空间。

| 入口 | 流程与行为 |
| --- | --- |
| 首次登录 | 微信登录 → 幂等创建个人空间 → 收藏页；再次登录不重复建空间 |
| 情侣邀请 | 我的 → 创建情侣空间 → 邀请；另一人登录后确认加入；过期、重复或满员给明确提示 |
| 收藏录入 | 选择空间 → 文字或链接 → 确认标题类型 → 保存 → 详情；不自动分享至其他空间 |
| 内容管理 | 作者新增空间收藏并编辑正文，成员可移除当前收藏；他人笔记不可转存到其他空间；分类标签筛选，轻量搜索可按需增加 |
| 长期偏好 | 我的 → 编辑本人记忆 → 保存；共同决策授权需明确说明会在所选空间的推荐理由中披露相关内容；不开放全部记忆列表 |
| 决策 | 当前空间 → 需求与条件确认 → 生成 → 展示排序选项、理由、来源与未知信息 |
| 反馈 | 参与人可改选，当前 Session 只有一个采纳结果；旧组可采纳拒绝，换批仅最新组可执行；记录页查看历史 |

链接只保证原地址保存，无法解析时允许手工补充；不编造正文、地址、价格或成分。个人空间使用本人，情侣空间使用实际参与成员，不伪造尚未加入者的偏好。用户创建多个空间不应受唯一 SpaceID 设计限制，具体类型与创建配额在空间 API 阶段确定。

## 3 决策体验与异常

select 每个选项引用一个 Note，最多三个，候选不足如实返回。只选候选内收藏，不为凑数量生成新商户。明确硬约束不能放宽；必要硬约束事实未知时不返回可采纳推荐，提示补充信息；只有软信息未知可随选项展示。预算按全部参与人的总额计算，时长按一次共同活动计算。

自然语言与表单条件冲突时确认后再生成；本次临时需求不自动写入长期记忆。反馈针对选项，拒绝不代表永久排斥其素材。换批保留已确认条件并尽量减少重复；需求或条件改变开启新 Session，不继承旧排除集合。

| 状态 | 行为 |
| --- | --- |
| 初次加载或空列表 | 加载与真实空态分开；空态提供新增入口 |
| 保存中或失败 | 禁重复提交，失败保留输入，确认落库后才显示成功 |
| 编辑冲突 | 保留本地输入，展示最新版本，不覆盖他人更新 |
| 生成中或取消 | 加载、禁重复生成、允许取消；晚到结果不覆盖新请求 |
| 超时或无匹配 | 保留条件，说明原因，允许重试或补收藏 |
| 换批失败 | 恢复原组及操作，不丢失原结果 |
| 空间切换或会话失效 | 清理不适用候选与 Session，重新授权，不自动重放写操作 |
| 来源删除或授权撤回 | 未来读取和召回按实时权限处理，历史快照有明确保留规则 |

建议未保存退出提示继续编辑或放弃；本地草稿不跨身份恢复。独立待用、完成计划和执行后评价不计入当前 P0。

## 4 后续路线

| 阶段 | 能力 |
| --- | --- |
| P1 内容增强 | 图片、多模态、自动标签、去重与受支持的链接解析 |
| V1.5 分享 | 授权分享笔记或清单，区分引用收藏与复制为本人笔记 |
| V2 市场 | 公开发布、浏览搜索收藏、基础审核与撤回授权 |
| V3 协作 | 多人空间、参与人选择、记忆优化与评测驱动的混合检索 |
| 规划能力 | day_plan 与 trip_plan，专项验证日期、时间、预算和信息真实性后开放 |

## 5 产品验收

两个账号能完成私人/情侣收藏与决策反馈；空间数据隔离；双方硬约束参与校验；Top 3 可解释且不足如实返回；历史可追溯；小程序真机可用。具体任务验证证据集中记录在任务清单，不在各文档重复维护。
